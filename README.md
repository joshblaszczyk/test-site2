# ThomKat Fashion & Art Boutique — site preview

Static design preview (no backend, no payment keys). The cart works in the browser; checkout and all orders are simulated in the visitor's browser.

## Try the admin

Open `shop/admin/` (the old `/admin/` link redirects there) and sign in with the password **demo**. It is the real admin screens (orders, pieces, weekly uploads, consignors, commission, setup) running on made-up sample data (fake customers, fake consignors, fake keys). Everything you add is saved only in your own browser; the **Reset demo** bar at the top puts the sample data back. A consignor's "private link" (Consignors > pick one > Make a private link) opens `consignor.html` with that consignor's pieces, cut and checks. Nothing here is connected to a real shop, bank, key or customer.
