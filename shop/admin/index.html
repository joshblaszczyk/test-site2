Weekly uploads / Sales
Weekly sales spreadsheet
Review products sold during a Monday–Sunday week, amounts and order progress.
Order statusSold dateTransactionItem / productLocationStore pickup / ShippedOriginal priceCustomer's cutStore commission (we made)Items in transaction
Enter an amount and an optional transaction number in a sold item's shipment details. Items with the same transaction number are counted as one order; items without one are counted separately. A transaction is complete only when all its items are marked complete. The customer's cut is the amount sold times the customer's split (40% or 50%), which you set in the same place.
